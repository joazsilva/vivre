# Vivre L'amour - Site de Vendas

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador.
4. Para melhor experiência, use a extensão **Live Server** no VS Code.

## Importante: WhatsApp
No arquivo `script.js`, altere:

```js
const WHATSAPP_NUMBER = "5599999999999";
```

Para o número real da loja, no formato:
- código do país + DDD + número
- sem +, espaços ou traços

Exemplo:
`5599988887777`

## Funcionalidades prontas
- Catálogo dividido por seções
- Filtro por categorias
- Modal com tamanho, cor e quantidade
- Carrinho persistente com localStorage
- Aumentar, diminuir e remover produtos
- Carrinho permanece após atualizar a página
- Formulário do cliente
- Envio do pedido completo para o WhatsApp
- Formulário para captar revendedoras
- Busca de produtos
- Layout responsivo
- Estrutura simples em HTML, CSS e JavaScript
